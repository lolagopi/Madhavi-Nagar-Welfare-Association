# Madhavi Nagar Welfare Association Dummy Website

This is a single-file static website. No installation or build step is required.

## Run locally
Open `index.html` in a web browser.

## Publish free with GitHub Pages
1. Create a new public GitHub repository.
2. Upload `index.html` to the repository root.
3. Open repository Settings > Pages.
4. Under Build and deployment, choose Deploy from a branch.
5. Choose branch `main` and folder `/ (root)`, then Save.
6. GitHub displays the published Pages address after deployment.

## Safety
All names, numbers, money values, and transactions are fictional demo data. Review organizational policy before publishing work-related code publicly.
